# Linux Utility
This repository is part of a collection of utilities designed to work together seamlessly. While each utility can be used independently, the best experience comes from pulling the entire repository to your machine and leveraging them as a complete suite.

## Getting Started

To enjoy the full benefits of these utilities, follow these steps:

1. **Clone the Repository**
   ```sh
   mkdir linuxUtility
   cd LinuxUtility
   git clone https://github.com/cruiz007/LinuxUtility.git   
   ```

2. **Explore the Utilities**  
   Browse through the different utilities available in this repo to understand their functionalities and dependencies.

3. **Set Up Your Environment**  
   Some utilities may require specific configurations, dependencies, or environment variables. Check the documentation for each utility to set them up properly.

## Why Use the Full Repo?
- Utilities are designed to complement each other.
- Shared dependencies and configurations make setup easier.
- Maximizes functionality and integration between tools.
- Reduces the need of mistakes in coping and pasting.
